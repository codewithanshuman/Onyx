        Developers
        
Drop it in.
Ship today.

        
Plain HTML classes and data attributes. Works with React, Vue, Svelte, Astro, or a single index.html.

        
    
          
  • No build stepLink one CSS file and you're done.
    • 
          
  • Behaviors without boilerplateModals, tabs, menus and toasts wire themselves up.
    • 
          
  • Brand it in minutesOverride tokens like --ox-radius to make it yours.
    • 
        

      


      

        

        

          
          
          
        

        


<!-- 1. Add Onyx -->
<link rel="stylesheet" href="onyx.css">

<!-- 2. Use it -->
<body class="ox">
  <button class="ox-btn"
          data-ox-modal-open="hello">
    Say hello
  </button>
  <script src="onyx.js"></script>
</body>

        

        


// Everything also has a tiny JS API
Onyx.modal.open("hello");

Onyx.toast("Saved", { duration: 3000 });

Onyx.theme.set("dark");
Onyx.theme.get(); // → "dark"

        

        


/* Make it yours */
:root {
  --ox-radius: 2px;
  --ox-radius-lg: 4px;
  --ox-font-sans: "Inter", sans-serif;
}

/* Invert any region */
<section class="ox-invert">…</section>

        FAQ
        
Questions,
answered.

      

      

        
Can I really use only black and white?
Yes — that's the point. Onyx is built so hierarchy comes from type, weight, space and contrast. If your brand needs a color, set it on a single token and everything follows.

        
Do I need React or a build tool?
No. Onyx is plain CSS plus a small script. It works in any framework, or none at all.

        
What's the difference between Free and Pro?
Free includes every core component under the MIT license. Pro adds advanced components, full page templates, the Figma kit and a commercial license.

        
Can I cancel anytime?
Of course. Cancel from your account in one click — you keep access until the end of the billing period.

        
Is it accessible?
Every interactive component supports the keyboard, manages focus and uses proper ARIA roles. Black on white also gives you the highest contrast possible.
